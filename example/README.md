# Example app

</div>

Demo for `document_reader_sdk`. See the root [README](../README.md).
1. The example uses `android/libdocsdk/` and `../ios/Frameworks/docsdk.framework` when those files are already here
2. Repo root: `dart run tool/bootstrap.dart` (Windows: `scripts\bootstrap.bat`)
3. iOS: `cd ios && pod install` · set **your** Xcode Team
4. `flutter run` on a physical device
